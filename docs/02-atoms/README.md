# Atoms

Atoms are the smallest reusable components. In the Figma library, they live under **Base Components**.

Each item file contains an optional, item-specific landing-frame recipe. Build and validate the Atom first. Follow [Component Execution Mode](../06-governance/component-execution-mode.md) for pacing: offer its documentation after QA in **One by one** mode, or defer guide decisions until the approved batch is complete in **YOLO everything** mode. Create documentation only when the user approves it.
