# Build Roadmap

## Phase 0 — Discovery

Complete the brand questionnaire, collect approved brand assets and product inputs, resolve conflicts, approve the discovery brief, and lock the first-release component list.

## Phase 1 — Foundations

Create approved tokens, modes, Text Styles, Effect Styles, icons, logos, and mandatory Foundation guides.

For each Foundation item, create or update its mandatory guide immediately after its values, assets, or rules are ready. Do not ask a separate documentation question. The visible guide contains usage, representative examples, do-and-don't guidance, and a concise accessibility check when relevant. Keep inventories, implementation details, and QA evidence in the Markdown specification or build ledger.

## Phase 2 — Atoms

Build and validate the smallest reusable controls and visual elements.

After each Atom passes internal component QA, ask whether to build its optional designer documentation. If approved, show its purpose, usage, actual permutations, do-and-don't examples, and concise accessibility status.

## Phase 3 — Molecules

Combine atoms into focused components such as fields, groups, menus, and feedback.

After each Molecule passes internal component QA, ask whether to build its optional designer documentation. If approved, show its purpose, usage, actual permutations, do-and-don't examples, and concise accessibility status.

## Phase 4 — Organisms

Combine atoms and molecules into larger reusable interface regions without product-surface categories.

After each Organism passes internal component QA, ask whether to build its optional designer documentation. If approved, show its purpose, usage, actual permutations, do-and-don't examples, and concise accessibility status.

## Phase 5 — Patterns and integration validation

Document recurring tasks and validate the building blocks together without introducing page-level deliverables.

## Phase 6 — Release

Run accessibility, naming, token-binding, visual, responsive, and consumer-file checks. Publish in dependency order.
